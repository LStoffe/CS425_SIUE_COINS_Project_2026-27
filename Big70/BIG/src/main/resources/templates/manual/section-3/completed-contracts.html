3.4 Completed Contracts

The Completed Contracts Report is very similar to the Contracts in Progress Report with the main difference being the Completed Contracts Report shows information for jobs already completed. Because the jobs on the Completed Contracts Report are already complete, there is no more uncertainty about costs and thus all values on the report are accurate. The columns from the Contracts in Progress Report that were estimates are no longer needed, so the Completed Contracts Report is much shorter than the Contracts in Progress Report.

All columns on the Completed Contracts Report can be found in the Contracts in Progress Report and they will not be described again here.

Tip: The column names on the Completed Contracts Report are different than those on the Contracts in Progress Report, but it should be apparent which is which.
